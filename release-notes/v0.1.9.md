## What's new

- **English and Vietnamese.** TableX now speaks Vietnamese as well as English. Switch with the language button in the status bar (or **Settings → Appearance → Language**); the change applies at once.
- **Put the results where you want them.** The **Results** header has a place menu: **Below** the editor, to the **Right** of it, in a **tab** of their own or in a **window** of their own that you can move to another screen. **⌘6** (Ctrl+6) hides and shows the results; while they are hidden a strip says so and brings them back. The default place is in **Settings → Editor → Results position**.
- **Resize the editor and the results.** Drag the line between them to give the editor or the results more room.
- **A status line under every editor** (SQL, Redis, MongoDB script, and the aggregation pipeline's text mode) shows the line and column, what is selected, the language, and the file name with a dot while it is unsaved.
- **Vim keys (basic).** Normal, Insert, Visual and Visual Line modes with the common motions (`h j k l w b e 0 ^ $ gg G`), the operators `d c y` with them, `x dd yy p P D C`, `i a I A o O`, and undo and redo (`u`, Ctrl+R). Turn them on for every editor in **Settings → Editor → Vim keys**, or for one editor with the switch in its status line or the **Toggle Vim Mode** command; the current mode shows next to the switch.
- **Charts for MongoDB results**, with the same chart types as SQL results.
- **SQL inside MongoDB scripts is highlighted** as SQL, next to the shell statements.
- **A compact commit-mode button.** The SQL editor header has one **Auto / Manual** button with a menu instead of two wide buttons; in Manual mode Commit and Roll Back appear next to it, with the number of statements waiting.
- **Headers and toolbars fit narrow windows.** When there is no room, the SQL editor header and the results toolbar move their less used buttons into a **…** menu; Run, Apply, Discard and Export stay in view.
- **Clearer status text.** The results show "19 rows fetched · 96 ms" (with "200+" when more rows are waiting) and "Selected: 16 cells · 4 rows"; the status bar at the bottom shows the active connection and database.
- **The active tab stands out**, with the editor's background and a coloured line on top.
- The current row is tinted when you click a cell, and an empty result has a **Run** button.
- The query preview of a table or collection is highlighted and has a copy button.
- The MongoDB filter opens from a funnel button, as in SQL tables, and the MongoDB script toolbar is more compact, with full database names.

## Fixes

- Updated the bundled SQLite and several libraries to versions with published security fixes.
- Sorting a table by a column on the server was greyed out after the connection dropped; it is offered again and reconnects first.
- Escape now closes the MongoDB filter builder, so the next click on **Query** runs instead of only closing it.
- Decimal128 and double values of NaN or Infinity no longer break a chart; they count as empty.
- Long labels on a chart's horizontal axis (such as ObjectIds) are thinned out instead of overlapping.

## What's new

- **tablex for Linux and Windows (preview).**
  - **Linux:** `tablex-0.1.11-linux-x86_64` and `-linux-aarch64`, as an `.AppImage` or a `.tar.gz`. Needs glibc 2.31 or newer (Debian 11, Ubuntu 20.04, RHEL 9 and later), a Wayland or X11 session, and Vulkan or OpenGL.
  - **Windows 10 and 11 (x86_64):** a `setup.exe` that installs for your user (no administrator rights), or a portable `.zip`. Neither is code signed yet, so SmartScreen asks once: **More info** → **Run anyway**.
  - Saved passwords use the system keyring on Linux and the Credential Manager on Windows. On a Linux desktop without a keyring (i3, Sway, a bare X session…), tablex asks once whether to keep the key in a private file or not to save passwords. **Settings → Security** changes it later.
  - Previews: they do not update themselves (tablex tells you about a new release and opens its page). On Windows, `tablex-mcp` cannot yet ask the running app to open a table or a query.
- **A richer sidebar.**
  - **Reconnect**, **Disconnect All** and **Disconnect All in Group**.
  - **New View…, New Index…, New Function…, New Trigger…** and more, from the menu of a connection, schema or table. Each opens an editor with a template.
  - **Filter…** on a folder (tables, views, …) shows or hides names by pattern, such as `user_*` or `*_old`. **Filter Databases…** and **Filter Schemas…** work the same way.
  - **Copy Tables** (⌘C / Ctrl+C) in the tree, then **Paste** (⌘V / Ctrl+V) on another connection, database or schema, opens Data Transfer with them.
  - **Compare DDL With…** shows the differences between the definitions of two tables or views.
  - **Bookmarks**: **Add Bookmark…** on any object, then **Go to bookmark** from the sidebar.
  - New settings under **Navigation**: what double-clicking a connection does, **Expand on connect**, **Group by database type**, **Remember the tree** (open nodes come back after a restart), and **Show table sizes** (estimated rows and size next to each table).
- **The results grid.**
  - **Page Up / Page Down** move a screenful of rows. **Home / End** go to the first or last column of the row, and **⌘Home / ⌘End** (Ctrl on Linux and Windows) to the first or last row of the column.
  - **⌘A / Ctrl+A** selects every cell.
  - A vertical scrollbar you can drag.
  - A very large value (a long text or JSON) is edited in the **Value** panel, and saved whole.
  - **Export** of a large page runs in the background and writes straight to the file.
- **More Vim.**
  - Search with `/ ? * #` (and `n` / `N`), `.` repeat, counts, text objects, `zt` / `zz` / `zb`, and a short highlight on yank.
  - A **Vim** group in **Settings → Editor**: the mode an editor starts in, the system clipboard (always, on yank, never), an escape sequence such as `jk`, the yank highlight time, whether Vim takes the Ctrl keys, and **Search ignores case** with **Smart case**.
- **The Welcome tab** has start actions (New Connection, New Query, Open SQL File, Import Connections, Driver Manager), your recent connections, the main shortcuts and links. With no driver installed yet, it offers **Install Drivers**.

## Fixes

- **macOS:** after an update the Dock and Finder showed the old icon until a restart. The new icon now shows at once, and the copy of the previous version is removed only once the new one has started.
- A settings file that cannot be read is set aside as `settings.json.corrupt` instead of being replaced, and an earlier one is never overwritten.
- When no supported graphics driver is found, tablex says so and what it needs instead of crashing.

## Before you update

- Going back to 0.1.10 afterwards loses your bookmarks and folder filters (0.1.10 does not know them). Connections, saved passwords, settings and scripts are kept either way.
- Update the drivers and `tablex-mcp` in **Driver Manager**: they were rebuilt with dependency security updates, and `tablex-mcp` 0.1.7 reads passwords the way tablex 0.1.11 saves them on Linux.

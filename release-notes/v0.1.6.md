## What's new

- Sort from a column header: every column has a sort button whose menu sorts the whole query in the database or only the loaded page, ascending or descending, and clears the sort. It works on SQL tables, SQL query results and MongoDB collections.
- A theme menu next to Settings in the title bar: Light, Dark or System.
- MongoDB tree view: click a row to select it, drag across rows to select text as in the JSON view, and press ⌘C to copy. Right-click a row to copy its value, field name, path or JSON.
- The MongoDB query preview can be selected and copied, and is highlighted.
- AI agents (the assistant and the MCP server) get a default access level for every connection in **Settings → AI → Default agent access**: Off (the default), Schema only or Read. Production connections stay off, and writes still need **Read and write** on the connection itself.
- With Schema access, agents can also read the definitions of functions, procedures, triggers and events.
- **Driver Manager → Tools** has an **Allow Keychain access** button for the MCP server, so macOS asks for the saved passwords once instead of during an agent's work (needs tablex-mcp 0.1.2).

## Fixes

- "_id cannot be changed." no longer stays on screen after you move from the `_id` cell to another cell.
- **Clear Filter** keeps the filter builder open on one empty rule instead of closing it.

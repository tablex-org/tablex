## What's new

- Install updates from inside TableX: when a newer version is out, **Install & Restart** downloads it, checks its signature and replaces the app. This starts with the next version; 0.1.5 itself is installed by hand.
- Connections recover by themselves after the Mac sleeps or a server restarts: a read reconnects and runs again once, and a write is never run twice.
- Idle connections are checked every 60 seconds so a dead one is noticed before you use it (**Settings → Query → Connection keep-alive interval**, 0 turns it off, can be set per connection).

## Fixes

- A query on a server that stopped answering no longer spins forever: **Cancel** frees it within about 10 seconds, and other tabs on the same connection are not stuck behind it.
- **Run** on a connection that had dropped reconnects instead of cancelling itself.
- The sidebar and the MongoDB index view no longer wait behind a stuck query.
- Quitting no longer hangs on a dead connection.
- Update the drivers in **Driver Manager** (PostgreSQL, MySQL, MariaDB and ClickHouse 0.1.1, MongoDB 0.2.3) to get the driver side of these fixes.

## What's new

- **Run runs the statement at the cursor.** Run and Ctrl+Enter (⌘Enter) now run the statement under the cursor, or the selection, as other database tools do; **Run Script** (Option+X) runs the whole script. If you prefer the old behaviour, set **Settings → Editor → Run executes** to **Whole script**. MongoDB script tabs follow the same setting.
- **SQL on MongoDB.** In a MongoDB script tab, `SELECT … FROM "database"."collection" WHERE … GROUP BY … ORDER BY … LIMIT …` runs as the matching `find` (or `aggregate` for JOIN, GROUP BY, HAVING, DISTINCT, COUNT, SUM, AVG, MIN, MAX and aliases), so queries written for other database tools work as they are. INNER and LEFT JOIN read another collection of the same database (one `ON a.x = b.y` each), and HAVING filters the groups. WHERE takes `=`, `!=`, `<>`, `<`, `>`, `IN`, `LIKE`, `IS NULL`, `BETWEEN`, `AND`, `OR`, `NOT` and parentheses; `--` comments are read too. SQL and shell statements can share one script.
- **MongoDB scripts run statement by statement**, as in a MongoDB shell: a statement that is wrong fails at its own line instead of stopping the whole script before it starts, and **Settings → Editor → On script error** decides whether the statements after it still run (needs the MongoDB Shell add-on 0.1.1).
- **More for MCP clients** (needs tablex-mcp 0.1.4): MongoDB queries and changes, scripts of several statements in one call, opening a table or a query in TableX, and adding, copying or removing connections. Every change is put to you first; see the tablex-mcp notes.
- The **Driver Manager** button in the title bar shows a dot when a driver or a tool (MCP server, MongoDB Shell, SQL Formatter) has an update, and tool updates are counted in the startup notice.
- Updated the UI toolkit (gpui-kit 0.10.0).

## Fixes

- After updating to 0.1.7, macOS asked for the Mac password twice for each saved password, and again on every connect when the second prompt was not answered. TableX now reads each password saved by an earlier version once, moves it into its own store, and never asks for it again.
- **Settings → Shortcuts** no longer refuses ⌘Enter for **Run Query** or **Run Script** as "Already used by Run the Filter". Enter in the MongoDB filter and sort fields still runs the filter there. Keys that cannot be changed now show which keys they are.
- In a MongoDB script tab, a statement left unfinished above no longer swallows the one under the cursor.
- A MongoDB Shell error in a selection or a single statement now names the line and column in the editor, not in the part that ran.
- A long line in a MongoDB Shell text result or in its Output scrolls sideways instead of being cut at the edge of the pane.
